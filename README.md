# Ticket Sales Application

## Назначение
Консольное приложение на Java для продажи билетов на мероприятия.
Поддерживает стандартные и VIP-билеты, покупку с учётом категории,
возврат, контроль вместимости и сохранение истории продаж в файл.

## Возможности
- Создание мероприятий с заданной вместимостью и ценами STANDARD/VIP
- Покупка билета с указанием категории и скидки
- Возврат билета с удержанием 20% стоимости
- Запрет продажи сверх установленной вместимости
- Отчёт по мероприятию: продано, свободно, разбивка по категориям, выручка
- Автоматическое сохранение и загрузка данных из файлов CSV
- Полная обработка некорректных данных (своя иерархия исключений)
